# 서울 미식

서울을 여행하는 사람이 이동 중에 확인할 수 있는 식당 운영·편의 정보 안내 서비스입니다.
맛집 순위나 리뷰보다 **지금 이용 가능한지**, **여행 중 필요한 편의시설이 있는지**, **어느 랜드마크 근처인지**를 빠르게 파악하는 데 초점을 둡니다.

## 서비스 방향

서울 미식은 “어느 구의 맛집을 찾나요?”보다 “지금 어디를 여행 중인가요?”라는 질문에서 시작합니다.

- 실제 API 응답의 인근 랜드마크를 여행 동선 빠른 선택으로 제공
- 구 단위 지역과 랜드마크를 조합해 식당 탐색
- 영업시간·휴무일·주차·배달 등 여행 중 필요한 운영 정보를 우선 노출
- 데이터가 없는 정보는 `-`로, 이용 불가 상태는 명확한 상태 표기로 안내

## 주요 기능

### 랜드마크 기반 탐색

API 응답에 포함된 `인근랜드마크명`을 집계해 실제 데이터가 존재하는 랜드마크만 빠른 선택 항목으로 보여줍니다. 선택한 랜드마크 주변 식당만 바로 확인할 수 있습니다.

### 지역 및 편의시설 필터

서울 25개 구를 ㄱㄴㄷ 순으로 선택할 수 있으며, 아래 조건을 복수로 적용할 수 있습니다.

- 주차 가능
- 배달 가능
- 와이파이 제공
- 놀이방
- 다국어 메뉴
- 스마트오더

### 여행자 중심 식당 카드

목록 카드는 한눈에 비교할 수 있도록 정보를 요약합니다.

- 구 단위 지역과 정상 운영 상태
- 인근 랜드마크
- 대표 메뉴
- 한 줄로 요약한 영업시간
- 주차·와이파이·배달 제공 여부

### 상세 운영 정보

카드를 선택하면 모달에서 상세 정보를 확인할 수 있습니다.

- 영업시간 및 휴무일
- 주차, 와이파이, 배달, 놀이방
- 다국어 메뉴, 스마트오더, 화장실
- 온라인 예약 정보
- 해시태그와 홈페이지
- 인근 랜드마크

긴 운영시간은 목록에서 한 줄로 줄이고, 상세 화면에서는 `|` 구분을 기준으로 줄바꿈해 읽기 쉽게 표시합니다.

### 페이지네이션

한 번에 10개 페이지 번호만 표시하며, `‹`와 `›`로 이전·다음 10페이지 묶음을 이동합니다.

## 데이터

서울관광재단의 **식당운영정보 Open API**를 사용합니다.

주요 활용 필드는 다음과 같습니다.

| 구분 | 활용 정보 |
| --- | --- |
| 기본 식별 | 식당 ID, 식당명, 지역명, 식당 상태 |
| 운영 | 영업시간, 휴무일, 온라인 예약, 홈페이지 |
| 편의시설 | 주차, 와이파이, 배달, 놀이방, 다국어 메뉴, 스마트오더, 화장실 |
| 여행 맥락 | 인근 랜드마크, 랜드마크와 거리, 해시태그, 대표 메뉴 |

- React 19
- Vite
- Tailwind CSS 4
- 서울관광재단 식당운영정보 Open API
- GitHub Pages

## 화면 원칙

- 메인 목록은 여행 중 빠르게 판단할 수 있는 정보만 한 줄 단위로 요약합니다.
- 상세 정보는 넓은 모달의 정보 그리드로 제공합니다.
- 미제공 값은 회색 배경의 `-`로 통일합니다.
- 실제로 불가한 값은 `🚫 불가`처럼 데이터의 상태를 구분해 보여줍니다.
